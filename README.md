# De Glimlachfabriek — statische website

Korte instructie:
1. Maak een repository aan op GitHub.
2. Upload alle bestanden in de root.
3. Ga naar Settings → Pages.
4. Kies de branch en publiceer de site.
5. De site verschijnt op:
   - https://<gebruikersnaam>.github.io
   - of via een repo-naam zoals: https://deglimlachfabriek.github.io

Wil je een echte contactformulier-backend, dan kun je later Formspree, Netlify Forms of een simpele serverless form integreren.
